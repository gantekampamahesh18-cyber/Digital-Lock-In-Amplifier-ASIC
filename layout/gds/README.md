Digital Lock-In Amplifier ASIC — GDS Layout

Overview

This directory contains the GDSII layout generated during the physical-design flow for the Digital Lock-In Amplifier ASIC, implemented using the SKY130A open-source PDK and OpenLane.

The GDSII file represents the physical layout produced from the synthesized RTL through floorplanning, placement, clock-tree synthesis, routing, and layout generation.

Project Details

- Project: Digital Lock-In Amplifier ASIC
- Design module: "lockin_top"
- Technology: SKY130A
- RTL language: Verilog HDL
- Physical-design flow: OpenLane
- Layout format: GDSII

GDS File

"lockin_top.gds"

The GDSII layout generated by Magic from the completed OpenLane physical-design run.

The layout contains the geometric representation of the chip, including standard-cell placement, interconnections, and other physical structures represented in the generated layout.

Viewing the Layout

The generated GDS can be opened using KLayout or Magic with the appropriate SKY130A technology configuration.

For example, to inspect the GDS in KLayout, run:

klayout layout/gds/lockin_top.gds

Ensure KLayout and the required technology files are configured correctly in your environment.

Physical Verification and Timing

GDS generation confirms that a layout file was produced. It does not, by itself, establish that all physical-design sign-off requirements have been met.

The final reports should be reviewed for:

- Design Rule Check (DRC)
- Layout Versus Schematic (LVS)
- Antenna violations
- Static Timing Analysis (STA)
- Setup and hold timing

In the recorded OpenLane run, the final extracted-parasitics timing results were:

Note: These are the recorded results from the existing run. Timing and antenna issues require further investigation before claiming sign-off readiness.

Purpose

This directory preserves the generated physical layout as part of the project's RTL-to-GDSII implementation journey.

The objective is to demonstrate the implementation of a digital signal-processing circuit from Verilog RTL through synthesis and physical design to GDSII layout generation using open-source ASIC tools.
